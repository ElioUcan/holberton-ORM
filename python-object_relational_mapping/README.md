# Python - Object-relational mapping

## Description
This project covers connecting to MySQL databases using Python's MySQLdb module and utilizing SQLAlchemy as an Object-Relational Mapper (ORM) to abstract database operations.

## Requirements
- Ubuntu 20.04 LTS with Python 3.8.5
- MySQLdb 2.0.x and SQLAlchemy 1.4.x
- Style: `pycodestyle` (version 2.7.*)
- All files are executable and documented.

## Files
- `0-select_states.py`: Lists all states from the database `hbtn_0e_0_usa`.
